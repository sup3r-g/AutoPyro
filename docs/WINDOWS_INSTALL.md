# AutoPyro для Windows x64

Для офлайн-установки нужен установленный 64-разрядный CPython 3.12 с `pip` и модулем `venv`. Распакуйте ZIP в папку, доступную для записи, и откройте там PowerShell.

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --no-index --find-links wheels --require-hashes -r install.lock
.\.venv\Scripts\python.exe -m pip check
.\.venv\Scripts\autopyro.exe
```

Если команда `py` недоступна, передайте полный путь к `python.exe` версии 3.12 в первой команде. Зависимости и их контрольные суммы входят в комплект. `dependency-licenses.csv` содержит сведения из метаданных пакетов. Лицензионные файлы сохраняются внутри оригинальных wheel.

## Проверка после установки

1. Откройте **Файл → Открыть таблицу как новый проект…** и выберите `examples\pyrolysis.csv`.
2. Нажмите **Прочитать / обновить предпросмотр**, проверьте колонки и примените импорт.
3. Сохраните проект `.apyro` в отдельной папке с рабочими данными. Откройте его снова и проверьте шесть проб.
4. Откройте **Файл → Отчёт…**, соберите отчёт и проверьте экспорт PDF и DOCX.

Настольный клиент подключается к существующей PostgreSQL с ролью только для чтения. Развёртывание базы и администрирование схемы выполняются из исходного репозитория с SQL и документацией в папке `database`.

## Обновление и удаление

Распакуйте новый выпуск в другую папку и установите его теми же командами. Откройте копию одного рабочего проекта, прежде чем переносить повседневную работу на новый выпуск. При сохранении поверх проекта старого формата AutoPyro создаёт рядом резервную копию исходного файла.

Для удаления программы выполните команду из папки выбранного выпуска.

```powershell
.\.venv\Scripts\python.exe -m pip uninstall autopyro
```

После этого можно удалить распакованный комплект и его окружение. Проекты и отчёты храните за пределами папки установки.
