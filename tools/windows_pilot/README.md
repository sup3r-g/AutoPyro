# AutoPyro для проверки на втором ПК

Для Windows x64. CPython 3.12.10 x64 включён в папку `runtime`, а пакеты приложения — во внутренний ZIP. Установка работает без сети и без прав администратора.

Распакуйте **весь ZIP** в доступную для записи папку с коротким путём, например `C:\AutoPyroPilot`. Откройте в ней PowerShell и выполните одну команду:

```powershell
.\install-and-check.cmd
```

Оставьте окно открытым до сообщения «Контроль пройден». Скрипт сверит SHA-256 внутреннего ZIP, создаст чистое окружение, установит пакеты с проверкой хешей и откроет тестовое окно AutoPyro. Контроль использует рабочую копию комплектного проекта, проверяет экспорт и восстановление после двух автосохранений. По окончании скрипт напечатает путь к протоколу и к установленному `autopyro.exe`.

В папке `runs\<запуск>\control` находятся `result.json`, `comparison.json`, PDF, DOCX и JSON отчёта. Для приёмки приложите первые два файла и просмотрите PDF и DOCX на рабочем экране. Шаблон карточки лабораторной серии находится в `control\series-record.md`.

После установки оставьте папки `runtime` и `runs` в исходном расположении. Для переноса распакуйте ZIP на новом месте и снова выполните команду.

При ошибке команда вернёт ненулевой код. Сохраните вывод терминала и файлы из папки запуска. Каждый повтор создаёт отдельное окружение и сохраняет результаты предыдущих проверок.
